# 烧饼工坊 - 原生微信小程序电商项目（Mock 版 V2.0）

基于原生微信小程序开发的电商购物平台，**全部功能基于 Mock 数据实现**，无需后端即可完整体验。

## 技术栈

- **框架**：微信小程序原生开发（非 Taro / uni-app），style v2，原生导航栏
- **请求层**：`api/http.js` 统一收口，`USE_MOCK = true` 走本地 Mock；联调真实后端只需改为 `false` 并切换 baseUrl
- **Mock 体系**：`mock/` 目录统一管理数据与路由，写操作内存 + storage 双写，跨页面一致
- **图片**：picsum.photos 固定 seed（刷新不变、各不相同），`binderror` 回退本地默认图
- **主题色**：`#eb4450`

## 快速开始

1. 用微信开发者工具打开本目录（AppID 可使用测试号）
2. `project.config.json` 已设置 `urlCheck: false`，可直接加载 picsum 图片
3. 所有页面均可交互，无需登录（Mock 用户已自动注入）

## 核心流程

- **浏览**：首页 → 分类 / 搜索 → 商品详情（多图轮播、SKU 选择、评价、看了又看）
- **加购**：详情页选规格 → 加入购物车（角标全局同步）
- **下单**：购物车结算 → 支付确认 → mock 支付 2s → 生成订单（待发货）→ 跳转订单详情
- **订单流转**：待付款 → 支付 → 待发货 → 模拟发货 → 配送中 → 模拟派送 → 待收货 → 确认收货 → 已完成
- **评价**：已完成未评价订单 → 去评价（星级 + 标签 + 晒图）→ 详情页评价区即时刷新
- **收藏**：详情页心形收藏，跨页面同步，收藏页管理

## 深挖功能（V2.1）

### 一、商品收藏与浏览足迹
- **收藏**：详情页心形按钮切换（storage `goods_collect` 存 goodsId 数组），收藏页 Tab（全部/正在热卖/即将上线）+ 左滑删除 + 空态；我的页收藏数量角标
- **浏览足迹**：进入详情自动记录（`browse_history`，去重移前、上限 50）；足迹页按 今天/昨天/更早 分组、左滑单删、清空全部（二次确认）；我的页「浏览足迹」入口

### 二、搜索增强
- **搜索历史**：`search_history` 数组（去重移前、上限 15），焦点态展示、单条删除、清空（二次确认）
- **热门搜索**：10 个热门词胶囊，点击直接搜索
- **搜索联想**：300ms 防抖，前缀匹配（最多 10 条），高亮匹配字符，点击跳详情
- **结果页**：商品卡（图/名/价/销量/加购）+ 排序（综合/价格升降/销量）+ 上拉分页 + 空态

### 三、收货地址管理
- **地址列表页**（`pages/address/list`）：管理/选择双模式，卡片含标签胶囊（家/学校/公司/其他）+ 默认绿色标识，左滑删除（默认不可删），底部新增按钮
- **地址编辑页**（`pages/address/edit`）：新增/编辑复用，省市区三级联动 picker + 标签单选 + 默认开关 + 手机号校验
- **联动**：购物车/支付页点地址区跳列表（选择模式），选中设为默认并回填

### Mock 种子数据
- 初始收藏 8 条、浏览足迹 18 条（近 7 天）、搜索历史 8 条、地址 5 条（含默认 + 标签 + 省市区）
- 商品扩充至 50 条，覆盖全部热门搜索词

## 深挖功能（V3.0：抢购/券/积分/签到/消息）

### 一、限时抢购
- 首页轮播下「限时抢购」区：10:00/14:00/20:00 三场，当前场高亮，实时倒计时（时:分:秒），到期自动切场
- 横滑商品卡：抢购价（红色加粗）+ 原价划线 + 已抢% 渐变进度条 + 剩余库存 + 「马上抢」
- 规则：每场 7 个商品、限时 2 小时、每人每场每商品限 1 件；抢光/到期置灰
- 全场页 `pages/seckill/index`

### 二、优惠券系统
- **领券中心** `pages/coupon/index`：10 张券模板（6 满减红/2 折扣橙/2 无门槛金），「立即领取」每人每券限 1 张，已领置灰
- **我的券**：Tab（未使用/已使用/已过期），临期红色标识，「去使用」
- **下单联动**：支付页自动匹配最优可用券，券弹层（可用勾选/不可用置灰+原因"未满59元"），金额重算（总价-满减-券=实付）

### 三、会员积分
- 积分获取：购物每1元=1积分、签到+5、评价+20
- **积分中心** `pages/points/index`：头部积分卡 + 明细（+绿/-红）+ 兑换专区（100/200/500积分兑券、800积分免费兑商品），积分不足置灰
- 初始 680 积分 + 17 条记录

### 四、每日签到
- **签到页** `pages/checkin/index`：当月 7 列日历（已签✓/今日描边/未来灰）、连签梯度（+5/+5/+10/+10/+15/+20/+50）、签到成功弹层、断签重计、翻月查看
- 初始连签 3 天、当月已签 8 天

### 五、消息通知中心
- `pages/message/index`：类型 Tab（全部/订单/促销/系统）、未读红点、点击已读+跳转（订单→详情/促销→领券或抢购/系统→展开）、「全部已读」
- TabBar「我的」未读角标（wx.setTabBarBadge）
- 推送场景：进入消息中心 3 秒后自动 push 促销、下单后写订单消息、券临期提醒
- 初始 18 条消息，3 条未读
